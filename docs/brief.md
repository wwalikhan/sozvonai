# Бриф проекта

SozvonAI — сервис для автоматической транскрибации деловых звонков и встреч предпринимателей. Пользователь загружает или записывает разговор, система расшифровывает речь в текст локально (без платных API транскрибации) и отдаёт готовый текст встречи.

Уникальная позиция — минимум платных внешних API: транскрибация работает на локальной модели Whisper, что снижает себестоимость по сравнению с конкурентами на OpenAI Whisper API / сторонних SaaS-транскрибаторах.

Для кого: предприниматели и бизнесмены, которые проводят переговоры и встречи и хотят получать текстовую расшифровку без ручного конспектирования.

На выходе MVP: рабочий сервис — загрузка аудио/видео звонка → локальная транскрибация через Whisper → просмотр и выгрузка текста расшифровки. Без базы знаний, без сложной аналитики — только рабочий цикл "загрузил → получил текст".
