| Live-транскрибация (WebSocket + faster-whisper) | 2 | ✅ готово, первый тест на реальном голосе пройден | `WS /ws/stream/{call_id}` (`app/main.py`), потоковая транскрибация по сегментам (`app/asr.py: transcribe_pcm`). 2026-09-25: первый прогон на настоящей русской речи пользователя (не TTS) — качество распознавания хорошее, найдена известная галлюцинация faster-whisper на паузе (см. `docs/issues.md`) |

Проверено на 4 реальных записях (человек+человек, человек+голос ИИ из динамиков через один микрофон) — во всех устойчиво держит верное число реальных участников |
| Минимальный UI live-звонка | 2 | ✅ готово | `static/live.html` — Start/Stop, захват микрофона, рендер текста по спикерам. Проверено сквозным браузерным тестом (Playwright + эмулированный микрофон) |
| Захват онлайн-звонков (tab capture) | 3 | ✅ готово, проверено вживую | `backend/static/live.html` — выбор режима "очная встреча"/"онлайн-звонок", `getDisplayMedia({video:true,audio:true})` + `getUserMedia` микс через общий `GainNode` → тот же PCM16-поток на `/ws/stream/{id}`, `source` (`mic`/`tab_capture`) сохраняется верно. 2026-09-25: ручной тест в реальном Chrome — звук вкладки (подкаст) и микрофон пользователя оба захватились и транскрибировались из одного смешанного потока. Черновая live-диаризация на смеси путалась (3-4 "спикера" вместо 2), но фоновая реконсиляция (Stage 4, offline pyannote) после звонка корректно развела ровно на 2 настоящих голоса — Speaker 1 = вкладка, Speaker 2 = микрофон. Связка Stage 3+4 подтверждена на реальных данных |
| Реконсиляция диаризации после звонка | 4 | ✅ готово, проверено | `backend/app/reconciliation.py: reconcile_live_call()` — после live-звонка в фоне (`run_in_executor`) прогоняет offline pyannote по записанному `audio.wav` и заменяет черновые метки (`is_final=False`) на точные (`is_final=True`). Сквозной тест (Playwright, синтетические голоса): реконсиляция уложилась в ~12-16с, черновые 3-4 live-спикера корректно свернулись в 2 реальных, 100% сегментов получили верную метку после реконсиляции, "уточняется…" в UI пропадает |
| Экспорт (txt/pdf) | 4 | ✅ готово (с минорной оговоркой) | `GET /calls/{id}/export?format=txt\|pdf` — `backend/app/main.py`. TXT проверен полностью. PDF через `fpdf2` с системным TTF (arial.ttf) — кириллица визуально рендерится корректно (проверено в Chromium), но `pdftotext`/poppler не извлекает кириллический текст из PDF (проблема ToUnicode CMap) — не блокирует использование, см. `docs/issues.md`. Путь к шрифту зашит под Windows — при деплое на Linux потребуется поправить |

Фронтенд: `static/login.html`, `static/js/session.js`+`api.js`, все 5 страниц ретрофичены. 2026-09-28: полный сквозной тест через реальный Supabase-проект (Playwright, headless-браузер) — неавторизованный доступ корректно редиректит на логин и получает 401; регистрация через реальный Supabase Auth API; Supabase отклонил `@example.com` как плейсхолдер-домен; реальное письмо-подтверждение получено и обработано (реальная ссылка подтверждения, не обход БД — попытка подтвердить email напрямую через SQL была намеренно заблокирована и не использовалась); вход по паролю → загрузка звонка → звонок корректно виден только своему пользователю (проверено SQL-запросом join на `auth.users`) → выход → повторный доступ снова заблокирован.
